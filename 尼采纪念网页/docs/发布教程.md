# 尼采纪念网页发布教程

发布前请保留整个文件夹结构，尤其是 `assets` 目录。不要只上传 `index.html`，否则图片和音乐会缺失。

## 方案一：Netlify Drop（最快）

适合第一次发布，不需要安装命令行工具。

1. 打开 [Netlify Drop](https://app.netlify.com/drop)。
2. 将整个 `尼采纪念网页` 文件夹拖入网页上传区域。
3. 等待上传和构建完成，网站会得到一个临时网址。
4. 注册或登录后，可在站点设置中修改站点名称，例如把随机名称改为更易读的 `nietzsche-memorial`。
5. 如绑定自有域名，在 `Domain management` 中添加域名，并按提示配置 DNS。

更新网站时，重新拖入更新后的文件夹即可。Free 计划的界面与额度可能变化，正式发布前请查看当前套餐说明。

## 方案二：GitHub Pages（免费、便于维护）

### 第一次发布

1. 登录 GitHub，新建一个公开仓库，例如 `nietzsche-memorial`。
2. 将本项目文件夹内的所有内容上传到仓库根目录。要确保根目录能直接看到 `index.html`，而不是多出一层同名文件夹。
3. 打开仓库的 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，保存。
6. 等待约 1–3 分钟，页面会显示类似 `https://用户名.github.io/nietzsche-memorial/` 的网址。

### 使用命令行上传

在本目录打开 PowerShell，依次运行：

```powershell
git init
git add .
git commit -m "Create Nietzsche memorial website"
git branch -M main
git remote add origin https://github.com/你的用户名/nietzsche-memorial.git
git push -u origin main
```

将 `你的用户名` 和仓库名替换为实际信息。第一次推送时需要登录 GitHub。

### 后续更新

修改文件后运行：

```powershell
git add .
git commit -m "Update memorial site"
git push
```

GitHub Pages 会自动重新发布。

## 方案三：Vercel

1. 打开 [Vercel](https://vercel.com/)，登录并选择 `Add New Project`。
2. 导入已上传到 GitHub 的仓库。
3. 本项目是纯静态网站，Framework Preset 选择 `Other`，Build Command 留空，Output Directory 留空。
4. 点击部署，完成后获得 `*.vercel.app` 地址。
5. 之后每次推送到 GitHub，Vercel 都会自动更新。

## 方案四：Cloudflare Pages

1. 登录 [Cloudflare Pages](https://pages.cloudflare.com/)。
2. 连接 GitHub 仓库，或直接上传项目文件夹。
3. 构建设置保持静态资源默认值：构建命令留空，输出目录保持项目根目录。
4. 部署完成后使用系统提供的 `*.pages.dev` 地址。
5. 可以在 Cloudflare 中绑定已托管于 Cloudflare 的自有域名。

## 发布后检查清单

1. 首页 1882 年肖像、蒙克画作、手稿和档案馆图片均正常显示。
2. 点击五个导航页，地址栏哈希能在 `#home`、`#life`、`#works`、`#ideas`、`#legacy` 之间切换。
3. 点击“开启声音，进入”后能听到背景音乐；手机浏览器仍需使用一次点击授权播放。
4. 著作筛选、书籍弹窗、思想星图按钮与“再抽一张思想签”均可操作。
5. 手机宽度下导航按钮可打开全屏菜单，页面没有明显横向滚动。
6. 发布的网址使用 HTTPS 时，音频、图片和站内链接都应使用相对路径，本项目已按此方式配置。

## 背景音乐说明

浏览器不允许普通网页在用户尚未交互时强制播放声音。本项目采用开场按钮触发播放，既符合常见浏览器策略，也让访问者可以选择静音浏览。

音乐文件为 50 秒、约 4.2 MB 的 WAV。若正式站点流量较大，可以在本地用音频工具转成 OGG 或 MP3，并同步修改 `index.html` 中的 `<audio src="...">`。转换时建议保留 20–40 秒缓冲，并保持循环首尾音量接近，减少接缝感。

## 常见问题

**打开后没有声音？**

先点击右上角“声场”或右下角音乐按钮。确认系统音量未静音，并检查发布平台是否完整上传了 `assets/audio/turiner-nacht-ambient.wav`。

**图片显示为空白？**

确认 `assets/images` 位于 `index.html` 同级目录，文件名大小写也要一致。GitHub Pages 的分支和目录应选择项目根目录。

**页面换页后出现 404？**

本站使用哈希路由，网址形如 `/#ideas`，正确发布根目录时不会需要单独的服务器重写规则。

**能否加入自己的域名？**

可以。先在 Netlify、Vercel、Cloudflare Pages 或 GitHub Pages 的域名设置中加入域名，再向域名注册商配置平台给出的 DNS 记录。首次生效通常需要几分钟到数小时。
